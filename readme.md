# Computer Vision Assignment Suite 🎯

A collection of four self-contained Python scripts that implement classic **digital image processing and computer vision** techniques from scratch (alongside OpenCV built-ins for comparison). The project covers image resampling, noise & denoising, hybrid/multi-resolution image blending, and edge detection — complete with quantitative evaluation (MSE/PSNR), error visualizations, and side-by-side comparison plots.

> Built as part of a Computer Vision coursework series (Q1–Q4), this repo demonstrates both "from-scratch" implementations (nearest-neighbour resizing, box filtering, 2D convolution) and built-in OpenCV equivalents so results can be directly compared.

## 🧠 What Each Script Does

### `q1.py` — Image Downsampling & Reconstruction Quality
Takes a **512×512 grayscale image**, downsamples it to 256×256 and 128×128, then reconstructs it back to 512×512 using three interpolation methods:

- **Nearest-Neighbour** — implemented **from scratch** (no `cv2.resize` shortcuts for this method)
- **Bilinear** — via `cv2.INTER_LINEAR`
- **Bicubic** — via `cv2.INTER_CUBIC`

For every combination it computes:
- **MSE** (Mean Squared Error)
- **PSNR** (Peak Signal-to-Noise Ratio, in dB)
- **Absolute Error** and **Squared Error** maps

...and renders a 3×3 grid of reconstructed images alongside their heat-mapped error maps, so you can visually see where each interpolation method loses the most detail.

### `q2.py` — Noise Simulation & Spatial Filtering
Simulates two of the most common types of image noise and evaluates four classic denoising filters against them:

- **Noise models:** Salt-and-Pepper noise, Gaussian noise
- **Filters:**
  - **Box Filter** — implemented **from scratch** via manual 2D convolution
  - **Weighted Average Filter** — center-weighted kernel via `cv2.filter2D`
  - **Gaussian Filter** — `cv2.GaussianBlur`
  - **Median Filter** — `cv2.medianBlur`

It sweeps across kernel sizes (3×3, 5×5, 7×7), reports PSNR for every filter/kernel combination, visualizes the **absolute difference maps** for 5×5 filters, and finishes with a **mixed-noise, region-wise smoothing** demo (salt-and-pepper on one half of the image, Gaussian on the other, each denoised with the filter best suited to it).

Uses `skimage.data.camera()` and `skimage.data.coins()` as sample images, so it runs out-of-the-box with **no external image files required**.

### `q3.py` — Hybrid Images, Alignment & Multi-Resolution Blending
The most advanced script — a full pipeline that:

1. **Aligns** two face images using detected eye landmarks (Haar cascades) and a similarity transform, with automatic fallback to a plain resize if landmarks aren't found.
2. Builds **hybrid images** in the **spatial domain** (Gaussian low-pass + high-pass filtering, per Perona/Oliva-style hybrid image equations) and sweeps multiple `sigma`/blend-weight combinations to auto-select the best-looking result.
3. Builds the same hybrid images in the **frequency domain** using 2D FFT-based low/high-pass filters, and times spatial vs. frequency approaches.
4. Performs **Gaussian/Laplacian pyramid blending** (classic Burt–Adelson multi-band blending) with a soft left/right blending mask.
5. Repeats the pyramid blend using an **edge-preserving bilateral filter** instead of a plain Gaussian, to compare detail preservation.
6. Prints a discussion of how alignment quality and sigma/threshold choices affect the results, plus a **summary table** across both image pairs.

If `face1_a.png`, `face1_b.png`, `face2_a.png`, or `face2_b.png` are missing, the script **synthesizes placeholder images** automatically so the whole pipeline still runs end-to-end.

### `q4.py` — Edge Detection: 1st vs. 2nd Order & LoG vs. Canny
Runs a comprehensive edge-detection comparison on two types of images (clean object boundaries vs. fine texture):

- **1st-order derivatives** — Sobel gradients in X and Y, computed with a **from-scratch 2D convolution** implementation, plus gradient magnitude & direction maps
- **Thresholding sweep** — binary edge maps at low/mid/high thresholds with edge-density and connected-component statistics
- **2nd-order derivative** — Laplacian edge map, compared against the 1st-order result
- **LoG (Laplacian of Gaussian)** — with a custom **zero-crossing detector**
- **Canny** edge detector for reference

It then **automatically scores and picks the best-suited method per image** based on edge continuity and density, and prints a justification tied to the actual numbers — plus saves annotated comparison figures. If the input PNGs are missing, it synthesizes shapes (for boundary testing) or a texture pattern (for fine-detail testing) so it still runs without external data.

## ▶️ How to Run

Each script is fully standalone and can be run directly from the command line. Make sure you're in the repository's root directory (where `img.png`, `face1_a.png`, `boundaries.png`, etc. live) before running.

### Q1 — Resizing & Interpolation Analysis
```bash
python q1.py
```
- **Requires:** `img.png` must be a valid **512×512 grayscale image** in the working directory.
- **Output:** Console log of MSE/PSNR per method + a pop-up Matplotlib figure of reconstructed images and error maps.

### Q2 — Noise & Filtering
```bash
python q2.py
```
- **Requires:** nothing extra — sample images are pulled automatically from `scikit-image`.
- **Output:** Console log of PSNR per filter/kernel size + two pop-up figures (absolute difference maps, mixed-noise smoothing comparison).

### Q3 — Hybrid Images & Pyramid Blending
```bash
python q3.py
```
- **Requires (optional):** `face1_a.png`, `face1_b.png`, `face2_a.png`, `face2_b.png`. If any are missing, synthetic placeholders are generated automatically.
- **Output:** Console log (alignment status, best parameters, timing, discussion, summary table) + saved figures `q3_Pair_1.png` and `q3_Pair_2.png` in the working directory.

### Q4 — Edge Detection Comparison
```bash
python q4.py
```
- **Requires (optional):** `boundaries.png`, `finedetails.png`. If missing, synthetic shape/texture images are generated automatically.
- **Output:** Console log (edge-density stats, best-method justification) + saved figures `q4_Image_A_-_Object_Boundaries.png` and `q4_Image_B_-_Fine_Details.png`.

> 💡 **Tip:** Run scripts one at a time — each opens its own Matplotlib window(s). Close the plot window to let the script continue/finish.

## 🧩 Key Concepts Demonstrated

- Image interpolation: nearest-neighbour, bilinear, bicubic
- Quantitative image-quality metrics: **MSE**, **PSNR**
- Noise modeling: salt-and-pepper, Gaussian
- Spatial-domain filtering: box, weighted average, Gaussian, median
- Image alignment via landmark detection + similarity transforms
- Hybrid images in the **spatial** and **frequency (FFT)** domains
- **Gaussian/Laplacian pyramids** and **multi-band (Burt–Adelson) blending**
- Edge-preserving smoothing with **bilateral filtering**
- Edge detection: Sobel (1st-order), Laplacian (2nd-order), **LoG with zero-crossing**, and **Canny**
- Custom from-scratch implementations of resizing, convolution, and zero-crossing detection alongside OpenCV built-ins for direct comparison
